1. W jaki sposób można określić właściwości danego obiektu (dwa sposoby wraz z przykładami)?

    Właściwości obiektu można określić dwoma sposobami:
    1. Za pomocą literału obiektu:
    var mebel = { rodzaj: "stół", material: "drewno", kolor: "brązowy" };
    2. Za pomocą konstruktora i słowa kluczowego new:
    function Mebel(rodzaj, material, kolor) {
    this.rodzaj = rodzaj;
    this.material = material;
    this.kolor = kolor;
    }
    var mebel1 = new Mebel("stół", "drewno", "brązowy");

  2. W jaki sposób można odwołać się do pól (właściwości) i metod?

    Do pól i metod odwołujemy się przez nazwę obiektu i kropkę:
    mebel.rodzaj – odwołanie do pola
    mebel.pokaz() – wywołanie metody
    Można też użyć zapisu tablicowego:
    mebel["rodzaj"] i mebel["pokaz"]().

  3. Wymień cechy charakterystyczne konstruktora.

    Konstruktor:
    - jest to specjalna funkcja służąca do tworzenia obiektów,
    - zwykle ma nazwę zaczynającą się od wielkiej litery,
    - przyjmuje argumenty, które są przypisywane do pól obiektu,
    - używa słowa kluczowego this, aby przypisać wartości do tworzonego obiektu,
    - tworzy wiele obiektów o podobnej strukturze.

  4. Konstruowanie obiektu na podstawie przykładu – obiekt ma trzy pola oraz jedną metodę.

    var mebel = {
    rodzaj: "stół",
    material: "drewno",
    kolor: "brązowy",
    pokaz: function() {
    document.write(this.rodzaj + "
    ");
    document.write(this.material + "
    ");
    document.write(this.kolor);
    }
    };
    Obiekt ten ma trzy pola: rodzaj, material, kolor oraz jedną metodę: pokaz.

  5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

    this oznacza obiekt, w którym aktualnie pracujemy. Dzięki temu metoda może odwołać się do pól tego samego obiektu.
    Przykład:
    this.rodzaj, this.material, this.kolor
    Pola i metody w obiekcie oddzielamy przecinkami, a ciało metody zapisujemy w nawiasach klamrowych.

  6. Konstruktor w JS na podstawie przykładu wraz z opisem.

    function Mebel(rodzaj, material, kolor) {
    this.rodzaj = rodzaj;
    this.material = material;
    this.kolor = kolor;
    this.pokaz = function() {
    document.write(this.rodzaj + "
    ");
    document.write(this.material + "
    ");
    document.write(this.kolor + "
    ");
    }
    }
    var mebel1 = new Mebel("stół", "drewno", "brązowy");
    Konstruktor jest wzorcem, z którego tworzymy wiele obiektów o podobnych właściwościach. Każdy nowy obiekt otrzymuje własne pola i metodę.

  7. Znaczenie słowa kluczowego new wraz z przykładem.

    new tworzy nowy obiekt na podstawie konstruktora. Dzięki temu zostają zainicjalizowane pola obiektu.
    Przykład:
    var mebel2 = new Mebel("krzesło", "metal", "czarny");
    Po użyciu new JavaScript tworzy nowy obiekt i przekazuje argumenty do konstruktora.

  8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem (szczególnie ważny tekst pogrubiony).

    prototype pozwala dodać wspólne metody i właściwości do wszystkich obiektów utworzonych z danego konstruktora.
    Przykład:
    function Mebel(rodzaj, material, kolor) {
    this.rodzaj = rodzaj;
    this.material = material;
    this.kolor = kolor;
    }
    Mebel.prototype.pokaz = function() {
    document.write(this.rodzaj + "
    ");
    document.write(this.material + "
    ");
    document.write(this.kolor);
    };
    Metody i właściwości zapisane w prototype są wspólne dla wszystkich obiektów utworzonych z konstruktora, dzięki czemu nie są duplikowane w każdym obiekcie osobno.
